# JOTAGALLO Portfolio

> Modern, bold, and dark single-page portfolio for a senior fullstack developer.

## 🎯 Purpose

This repository is open for **portfolio purposes** — showcasing a real-world Symfony application with modern frontend architecture, clean code principles, and creative design implementation.

## 🚀 About This Project

A single-page portfolio website built with:

- **Symfony 6** - PHP framework with clean architecture
- **Tailwind CSS v3** - Utility-first styling with custom theme
- **Twig** - Templating engine
- **YAML Data Layer** - Separation of concerns with service-based architecture
- **SVG Animations** - Custom animated backgrounds and logo
- **Responsive Design** - Mobile-first with hamburger menu

### Key Features

✨ Animated tech-themed hero background with circuit lines and glowing effects  
🎨 Custom neon red color palette with gradient effects  
📱 Fully responsive with mobile navigation  
🏗️ Service-based architecture following SOLID principles  
🎯 YAML-driven content management  
🎭 Custom SVG logo and favicon with animations
